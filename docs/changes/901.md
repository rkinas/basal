- **Gemma 4 on `--mode mps` keeps the sliding window** (`--mode mps`, basal-omni): one mask went through the
  transformers forward to every layer, so the sliding-window layers read whole states; the engine's own Gemma 4
  forward now runs there with its masks per layer type, as in `--mode eager`. Answers over states longer than the
  window change to eager's. [#901](https://github.com/rkinas/basal/pull/901).
- **Prepared kernels from the Hub only for trusted publishers** (`--prepared auto`): compiled kernels are code the
  compiler cache runs, so the ones a Hugging Face repository ships load only for the owners in
  `BASAL_PREPARED_TRUST` (comma-separated, `*` for every one; default `Remek`); a local model directory,
  `--prepared <dir>` and what `basal-prepare` wrote on this machine load as before.
  [#901](https://github.com/rkinas/basal/pull/901).
- **One code readout for every torch engine** (`--mode eager`, `fast`, `fast-exit`, `strix`, `basal-finetune`): the
  fp32 rows of the option codes, the head's bias and the final logit soft cap once, one masked softmax and one copy
  to the host. `--mode fast-exit` now applies the soft cap it skipped (its answers on soft-capped models change);
  eager answers can move in the last bits (one product per call); the graph engine's answers are unchanged. The
  long-shape warm-up of `--mode fast` runs after the one-forward limit is measured, so it warms the path long
  requests take. [#901](https://github.com/rkinas/basal/pull/901).
