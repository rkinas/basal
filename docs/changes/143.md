- **The TypeScript client refuses a 200 response without answers** (`clients/typescript`): a 200 body that is JSON
  but not a basal response (`{}`, `{"answers": []}`, `[]`, from a proxy or gateway) came back as a result without
  answers, and `null` threw a TypeError. It is now a `BasalError` of kind `server` with status 200, as the Python
  client raises `ServerError`. Contributed by Dariusz Koryto (@dkoryto),
  [#143](https://github.com/rkinas/basal/pull/143).
