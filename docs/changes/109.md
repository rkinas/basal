- **Prefix affinity in basal-router** (`--prefix-affinity on`, the default; `off`: the state's hash alone): a state
  that begins with one routed before (the next step of an agent trace or a chat, an edited document) goes to the
  replica that got that beginning, whose state cache then computes only the new tokens, while its load stays within
  2x `--load-factor`; states given as a list or an object get a routing key. /metrics and the router's page count
  requests routed by prefix. CPU, stub replicas, 64 traces x 12 steps: the share of state characters the replicas
  compute 0.277 -> 0.160 with 2 replicas, 0.469 -> 0.163 with 4 (one replica: 0.154). With replicas running
  basal's `StateCache` (4 GB LRU each; simulation by @piotrkowski), the share of prompt tokens computed for 64 agents
  0.59 -> 0.33 with 2 replicas, 0.66 -> 0.21 with 4, 0.76 -> 0.23 with 8. Contributed by Miłosz Kucharski
  (@Butterski), [#109](https://github.com/rkinas/basal/pull/109).
