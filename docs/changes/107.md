  graph shape once before its capture; now only each graph family's first shapes, in the same order (where torch.compile
  compiles), and the other shapes are captured directly (a shape that would compile again is warmed up as before).

  `--compile-scope layer` 98.6 -> 22.2 s and 256.5 -> 33.5 s; probabilities bit-identical. Contributed by Miłosz
