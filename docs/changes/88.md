- **`basal-bench` times llama-server and Ollama on prompts they have to compute** (`basal-bench`): the warm-up and the
  single-order call ran on the same prompt just before the timed call, so the prompt cache of an HTTP engine answered
  it almost for free and `lat1_ms`, `lat2_ms` and `dec_s` were too low. Each timed call now carries a random prefix
  (both option orders share it, so the second order still reuses the first); vLLM and SGLang are unchanged, as
  `cold()` already clears them. Latencies and throughput of llama.cpp and Ollama runs rise and are no longer
  comparable with earlier ones. Contributed by Rafal Wiktorowicz (NovaraX),
  [#88](https://github.com/rkinas/basal/pull/88).
