- **A rank question no longer fills the server with its own requests** (`rank`, `basal-serve`): a list in small
  chunks started every request at once (10,000 at `chunk: 1`), counted in flight without the `--max-requests` check,
  and every other client got 503 until it was done. At most 256 requests of a rank request now run at once, and at
  most half of `--max-requests`; the default chunk's 200 requests for 10,000 candidates still run together. With
  `chunk: 0`, a list with more candidates than `--max-branches` is answered in requests of 50 instead of refused.
  Contributed by Dariusz Koryto (@dkoryto), [#142](https://github.com/rkinas/basal/pull/142).
