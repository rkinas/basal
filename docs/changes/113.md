- **`basal-calibrate --keep-shipped TYPE`**: a question type keeps the compared file's temperature and thresholds
  together instead of being fitted, for a type your labels do not certify at a `max_error` the shipped file did
  (a fitted file would defer all its answers). The kept thresholds are marked `"kept": "shipped"`, measured on your
  CERT split, and listed in `fitted_on.kept_shipped`; the warning for an uncertified type names the option.
  Contributed by Dariusz Koryto (@dkoryto), [#113](https://github.com/rkinas/basal/pull/113).
