- **A long state no longer costs a tokenization per option code** (`basal-serve`, `basal-bench`, `basal-agree`,
  `basal-attach`, `basal-finetune`): the token ids of the option codes were read by tokenizing the whole prompt once
  per code (10, or 255 with prompt format 2), so a server whose first request had a 1 MB state spent seconds, or with
  format 2 minutes, before answering anything; they are now read at the prompt's end, where its tokens are those of
  the whole prompt (checked on every basal tokenizer: the same ids). Requests whose prompts hold over 64 KiB of text
  are prepared off the event loop. Answers are unchanged.
