- **`basal-serve` refuses more malformed requests with a 4xx before the GPU run** (`basal-serve`, `--api-keys`): a
  body nested too deeply answers 422 on `/v1/systemone` and 400 on `/v1/decisions` instead of a 500; an `act`
  question whose `base` is not `"choice"` or `"noul"` and a `multi` or `tool` question whose `threshold` is NaN or
  infinite answer 422 instead of a 500 after the run; an `--api-keys` file saved with a UTF-8 BOM (Notepad,
  PowerShell 5) is read instead of answering 401 to every request.
