- **A rank list too long for one shared context is answered in chunks** (`basal-serve`, `rank` questions with
  `"chunk": 0`): a list whose one shared context fits the model's context but would exceed `--max-prompt-mb` (every
  prompt holds that context) is now read in requests of 50 candidates instead of being refused with 422. With it,
  `basal-navigate`'s defaults work on `basal-serve`'s defaults again: its final stage reads the passages it reached in
  one shared context when it can, and in chunks when that would be too much text.
