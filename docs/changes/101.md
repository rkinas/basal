- **The CUDA cascade and compact rows on torch 2.11** (`--mode fast`, the Llama-based basal-2.0 models, sm80+): torch
  2.11 (the version README and INSTALL install) ran neither the cascade of pass 2 nor `--batches compact` off Hopper,
  because the engine asked torch's `varlen_attn` wrapper for `seqused_k` / `enable_gqa`; both now call the
  FlashAttention op it wraps, which takes them on 2.11 too. RTX 4060 Ti, basal-2.0-mini, torch 2.11: compress over
  1.5k-6k tokens 1.16-1.40x faster, 40 questions 1.12x, as on 2.13; answers as the cascade's on 2.13 (bf16 rounding).
  Compact rows on 2.13 bit-identical to 2.5.2. Contributed by Miłosz Kucharski (@Butterski),
  [#101](https://github.com/rkinas/basal/pull/101).
