- **Reuse shared state prefills within a call** (graph backends with StateCache): requests sharing an identical
  uncached state can reuse its prefill within `run_shared`, including GDN recurrent checkpoints. Temporary raw
  checkpoints have a 256 MiB per-call retention limit; repeated state extensions can also reuse a result that does
  not fit in StateCache. Calls containing split requests retain their original batching, and `--deterministic`
  behavior is unchanged. Contributed by @marcinbrzezanski,
  [#95](https://github.com/rkinas/basal/pull/95).
