- **basal-router spends less CPU per request** (`basal-router`; responses unchanged): the request body is parsed once
  and its routing key (the state with whitespace normalised, by split and join instead of a regular expression) is
  passed to the `--escalate` / `--blend` sub-requests, which parsed the body again each. CPU, stub replicas: 64 KB
  states 169 -> 233 requests/s at one client, 218 -> 318 at 32 (p95 342 -> 238 ms); 6 KB states 489 -> 547;
  cascades 265 -> 287, blends 167 -> 191 at 16 clients. Contributed by Miłosz Kucharski (@Butterski),
  [#108](https://github.com/rkinas/basal/pull/108).
