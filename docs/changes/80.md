- **The start-up 503 answers every HTTP method** (`basal-serve`): while the model loads, PUT, DELETE, OPTIONS and PATCH
  get the same `503 {"status": "starting"}` with `Retry-After: 5` as GET, POST and HEAD, not the 501 HTML page.
  Contributed by Rafal Wiktorowicz (NovaraX), [#80](https://github.com/rkinas/basal/pull/80).
