- **A split group computes its shared state once** (`--mode fast`, Llama models): a request with more than 8,192
  tokens of questions below its state (a `rank` stage over hundreds of passages in one context, navigate's last stage)
  is split into parts, and each part computed the same state again; the first part now computes it and the others
  read its keys and values (from the state cache, or without one from a store for the request when GPU memory allows).
  A100 80 GB, basal-2.0-4.5B, 300 candidates in one 26k-token context: 8.18 -> 6.09 s; the same P(yes). Contributed
  by Miłosz Kucharski (@Butterski), [#112](https://github.com/rkinas/basal/pull/112).
