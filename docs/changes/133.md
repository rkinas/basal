- **State cache files across engines (opt-in):** with `--state-cache-dir`, `--state-cache-import any-engine` also reads
  the files the other engine wrote for the same bf16 checkpoint (CUDA graph engine <-> `--mode mlx`), its own engine's
  file of a state first; Gemma 4's sliding layers of an imported long state are trimmed to the graph engine's window.
  The answers over those states are close to, not equal to, the uncached answers (Apple M4 Max, basal-2.0-mini, 300
  requests over graph-engine states: 298 / 300 top answers the same, max |dp| 0.026). The default `same-engine`
  reads only the engine's own files. [HARDWARE.md](HARDWARE.md#state-cache-disk-tier). Contributed by Paweł Kiszczak
  (@pawelkiszczak), [#133](https://github.com/rkinas/basal/pull/133).
